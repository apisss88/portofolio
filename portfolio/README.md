# Personal Portfolio Website

This project is the initial setup for a futuristic personal portfolio website for Hafiz Rizky Adkha Yanuar.

## Project structure

- `index.html` — main HTML entry point
- `style.css` — global reset, layout base, and design tokens
- `script.js` — general page initialization and basic logic
- `js/animation.js` — GSAP-based animation setup
- `js/three-scene.js` — Three.js scene setup
- `js/cursor.js` — custom cursor interaction
- `assets/images/` — image assets
- `assets/projects/` — project media
- `assets/icons/` — icon assets

## Libraries used

- GSAP
- ScrollTrigger
- Three.js
- Lucide Icons

## Notes

This is the Phase 0 initialization stage. The full portfolio sections and advanced interactions will be added in later phases.
